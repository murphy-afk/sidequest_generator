# Real Life Sidequests

A full-stack web application that gamifies real-world routines and exploration by turning daily activities into trackable quests, complete with verification mechanisms, progress tracking, and experience point progression.

## Tech Stack

* **Frontend:** React, Tailwind CSS, React Icons
* **Backend:** Node.js, Express
* **Database:** MySQL

## Features

* **Dynamic Quest Generation:** Generates real-world tasks based on parameters such as location type, budget, adventurousness, and mobility.
* **State-Driven Lifecycle:** Accept, pause, resume, and complete quests with persistent tracking across sessions.
* **Multi-Modal Verification:** Verifies quest completion via active timers, field checkpoint quizzes, and photo upload handlers.
* **User Progression:** Earn experience points (XP) and level up upon successful objective verification.
